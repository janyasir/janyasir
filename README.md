## 🚀 Current Areas of Work

### 🎥 Multi-Camera 3D Localization

Research and development of computer vision systems for estimating the 3D position of objects using multiple cameras, camera geometry, calibration, and image correspondences.

### 👁️ Computer Vision & Object Tracking

Development of AI-based systems for detecting, tracking, and analyzing objects in images and video.

### 🛰️ UAV Vision Systems

Exploring computer vision approaches for aerial platforms, including multi-camera perception, object localization, and real-time visual analysis.

### 🏏 Sports Computer Vision

Applying high-speed cameras, object detection, and tracking techniques to analyze fast-moving objects and events in sports.

### 📊 AI Analytics & Visualization

Building interactive applications and dashboards for exploring datasets, identifying trends, and presenting analytical results.
